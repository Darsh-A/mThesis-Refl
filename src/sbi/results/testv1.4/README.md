# test v1.4 — 4-D NPE detection on observed Li+22, yield-model cross-check

Applies the 4-D NPE (f_pisn, log10 f_ratio, log10 tpop2, M_pisn; NSF) to the
Li+22 catalogue and reports P(f_pisn > 0.5) per star — the PISN-dominated
probability — for each SN yield model.

- `Limongi18/` — trained on `dataset_TakaLimon_realisticNoise_v4_3.npz`
- `Nomoto13/`  — trained on `dataset_Nomotov5.npz`

Both use the 55-ratio Li+22-observable feature subset. Generated by
`src/sbi/apply_obs_4d.py <sn_source>`.

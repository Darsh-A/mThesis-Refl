# test v1.3 — non-ML (classical) inference vs NPE

Direct forward-model inference, no neural net:

- **4-D MAP** (scipy L-BFGS-B) over (f_pisn, log10 f_ratio, log10 tpop2, M_pisn)
  for 3 held-out stars.
- **emcee MCMC** over the same 4 parameters for one held-out star, giving a
  genuine non-ML posterior.
- The MCMC f_pisn marginal is overlaid on the NPE (test v1.1) marginal.

Uses the fast forward model (`make_forward_fast`, ~0.05 s/eval) so MCMC is
tractable. Generated by `src/sbi/nonml.py`.

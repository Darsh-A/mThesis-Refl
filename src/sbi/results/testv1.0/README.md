# test v1.0 — 1-D NPE for f_pisn

First end-to-end simulation-based inference test.

- **Inferred parameter (theta):** f_pisn (1-D), prior Uniform(0, 1).
- **Observation (x):** 105 pairwise [X/Y] abundance ratios (imputed, z-scored).
- **Density estimator:** Masked Autoregressive Flow (MAF) via `sbi`.
- **Data:** reused `src/randomForest/data/dataset.npz` (Takahashi PISN +
  Limongi18 SN, 2000 samples), keeping only f_pisn > 0 (pure-SN point mass dropped).

Generated by `src/sbi/train.py` and `src/sbi/evaluate.py`.

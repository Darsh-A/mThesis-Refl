# test v1.1 — 4-D NPE with observational noise

Multi-parameter simulation-based inference.

- **Inferred parameters (theta):** f_pisn, log10 f_ratio, log10 tpop2, M_pisn.
- **Observation (x):** 105 pairwise [X/Y] abundance ratios (imputed, z-scored),
  with realistic Li+22 element-sigma Gaussian noise added via
  `dataset.add_dex_noise` (correlated per element).
- **Density estimator:** Neural Spline Flow (NSF) via `sbi`.
- **Data:** reused `src/randomForest/data/dataset.npz` (Takahashi PISN +
  Limongi18 SN), keeping only f_pisn > 0 rows.

Generated by `src/sbi/train_multi.py` and `src/sbi/evaluate_multi.py`.
